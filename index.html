ANTICIPACIÓN EL PROBLEMA DEL RUNTIME
¿POR QUÉ TYPESCRIPT EN MÓVIL?

EL COSTO DE NO TIPAR EN PRODUCCIÓN

En JavaScript vanilla, los errores tipográficos o de estructuras de datos explotan en el teléfono del usuario.

🚨 JavaScript Vanilla (Sin Tipos)
function procesarPago(usuario, monto) { // Si usuario.perfil viene null/undefined... return usuario.perfil.descontarSaldo(monto); } // 💥 En tiempo de ejecución (App Crash en Android/iOS): // Uncaught TypeError: Cannot read properties of undefined

El error se descubre después de publicar el APK en la tienda.

🛡️ TypeScript (Seguridad Estática)
interface Usuario { perfil?: { descontarSaldo: (m: number) => boolean }; } function procesarPago(u: Usuario, m: number) { // 🛑 TypeScript bloquea la compilación antes de guardar: return u.perfil?.descontarSaldo(m) ?? false; }

0 errores en tiempo de ejecución. Autocompletado inteligente inmediato.

TRANSCOMPILACIÓN & TYPE ERASURE

¿QUÉ PASA CON LOS TIPOS AL EJECUTAR?

TypeScript es un guardián en tiempo de desarrollo. En tiempo de ejecución no existe sobrecarga de memoria.

01. ESCRIBIR
TypeScript (.ts / .tsx)

Escribes código con interfaces, uniones y tipos estrictos. VS Code analiza cada símbolo en tiempo real.

02. COMPILAR
Transpiler (tsc / Metro)

Type Erasure: El compilador elimina todos los tipos e interfaces. Genera JavaScript limpio y ultra-optimizado.

03. EJECUTAR
Hermes Engine / V8

El teléfono móvil ejecuta el bundle JS a máxima velocidad nativa sin el peso de validadores dinámicos.

💡 ANALOGÍA CON JAVA: En Java compilas `.java ➔ .class (Bytecode JVM)`. En TypeScript compilas `.ts ➔ .js (JavaScript estándar)`.

SINTAXIS 1 TIPOS PRIMITIVOS
JAVA VS TYPESCRIPT

DE LOS TIPOS DE JAVA A TYPESCRIPT

En TypeScript no hay int, float, double separados: todo número es number (64-bit IEEE 754).

☕ JAVA (Tipado a la izquierda) Estricto Nominal
// Primitivos en Java int edad = 17; double promedio = 9.85; String nombre = "Carlos"; boolean matriculado = true; // Arrays String[] notas = {"A", "B"}; List<String> cursos = new ArrayList<>();
⚡ TYPESCRIPT (Tipado con dos puntos :) Inferencia + Anotación
// Primitivos en TypeScript const edad: number = 17; const promedio: number = 9.85; const nombre: string = "Carlos"; const matriculado: boolean = true; // Arrays y Colecciones const notas: string[] = ["A", "B"]; const cursos: Array<string> = ["Móvil", "Web"];
Regla de Oro: Usa const por defecto y let solo si el valor va a mutar. ¡Nunca uses var!
FUNDAMENTOS DE TIPADO SLIDE 04 / 14
SINTAXIS 2 MODELADO DE DATOS
JAVA POJO VS TYPESCRIPT INTERFACE

MODELADO DE ENTIDADES PARA APPS

En desarrollo móvil con React Native, no necesitamos 80 líneas de Getters/Setters. Usamos Interfaces limpias.

☕ JAVA: Clase DTO con Boilerplate (30+ líneas)
public class Estudiante { private String id; private String nombre; private double calificacion; public Estudiante(String id, String n, double c) { this.id = id; this.nombre = n; this.calificacion = c; } public String getNombre() { return nombre; } // + getters, setters, toString, equals... }
⚡ TYPESCRIPT: Interface Concisa (6 líneas)
export interface Estudiante { readonly id: string; // Inmutable nombre: string; calificacion: number; avatarUrl?: string; // Opcional (?) } // Creación directa de objetos (Object Literal) const alumno: Estudiante = { id: "EST-01", nombre: "Mateo", calificacion: 10 };
MODELADO LIMPIO EN TYPESCRIPT SLIDE 05 / 14
CONCEPTO MAESTRO TIPADO ESTRUCTURAL
NOMINAL (JAVA) VS ESTRUCTURAL (TS)

"DUCK TYPING": LA FORMA ES LO QUE IMPORTA

En Java dos clases con los mismos atributos no son compatibles si no heredan de la misma clase. En TS, si tienen la misma estructura, ¡son compatibles!

☕ Java: Tipado Nominal

Dos objetos solo son del mismo tipo si fueron declarados explícitamente con la misma clase o interfaz.

class Punto2D { int x, y; } class Coordenada { int x, y; } Punto2D p = new Coordenada(); // ❌ ERROR DE COMPILACIÓN EN JAVA

⚡ TS: Tipado Estructural

"Si camina como pato y suena como pato, TypeScript lo trata como pato".

interface Punto { x: number; y: number; } const gps = { x: 10, y: 20, ciudad: "Cuenca" }; function dibujar(p: Punto) { ... } dibujar(gps); // ✅ VÁLIDO (cumple con x e y)
MODELO CONCEPTUAL DE TIPADO SLIDE 06 / 14
SUPERPODER DE TS UNION TYPES & NARROWING
MODELANDO ESTADOS DE PANTALLA

UNION TYPES & LITERAL TYPES

En React Native, una pantalla móvil pasa por estados exactos. En TS los modelamos con precisión quirúrgica.

🎯 Literal Types & Union Types
// En lugar de String genérico o Enums pesados: export type EstadoPeticion = | "inactivo" | "cargando" | "exito" | "error"; export type RolUsuario = "admin" | "docente" | "estudiante"; let estado: EstadoPeticion = "cargando"; estado = "fallo"; // ❌ Error: "fallo" no existe
🔍 Discriminated Unions (Estado Completo)
type RespuestaAPI = | { status: "loading" } | { status: "success"; data: string[] } | { status: "error"; mensaje: string }; function renderUI(res: RespuestaAPI) { if (res.status === "success") { // TS sabe automáticamente que res.data EXISTE console.log(res.data.length); } }
CONTROL DE FLUJO SEGURO EN APPS SLIDE 07 / 14
FUNCIONES TIPADAS PARÁMETROS Y RETORNOS
ARROW FUNCTIONS EN REACT NATIVE

FUNCIONES Y ARROW FUNCTIONS

En React Native, los componentes y manejadores de eventos son funciones. El tipado de parámetros previene bugs.

⚡ Función con Retorno Explícito
// Parámetros tipados + Retorno estricto export const calcularDescuento = ( precio: number, porcentaje: number = 10, // Default param cupon?: string // Optional (?) ): number => { if (cupon === "SALESIANO") { return precio * 0.5; } return precio - (precio * (porcentaje / 100)); };
📱 Funciones Asíncronas (Promesas / APIs)
interface Pokemon { name: string; url: string; } // Retorno tipado con Promise<T> export const obtenerPokemon = async ( id: number ): Promise<Pokemon> => { const res = await fetch(`https://pokeapi.co/api/v2/pokemon/${id}`); return await res.json(); };

MODULARIDAD ES MODULES & DESTRUCTURING
JAVA PACKAGES VS ES6 MODULES

ORGANIZACIÓN MODULAR Y PROPS

En TypeScript exportamos e importamos de forma granular. La destructuración permite extraer variables limpiamente.

📦 Módulos (import / export)
// archivo: services/auth.ts export interface Session { token: string; } export const login = () => { ... }; // archivo: screens/LoginScreen.tsx import { Session, login } from "../services/auth";
✨ Destructuración de Objetos y Arrays
const alumno = { nombre: "Ana", curso: "3 BGU", paralelo: "E1" }; // Extraer campos directamente: const { nombre, paralelo } = alumno; console.log(`${nombre} está en el paralelo ${paralelo}`); // Destructuración de Arrays: const coords = [-2.8974, -79.0045]; const [latitud, longitud] = coords;
